Evaluation dashboard

Drop summary files here, or use “Add run summaries”.

Create them with python -m dreamerv3_attention.dashboard (every run in runs/experiment_28/evaluation), or pass evaluation directories or training metrics.jsonl files. They are written to runs/dashboard/.

Overview

Run totals for the filtered episodes. Arrows compare with the baseline run. Rates use total distance or total steps, not the mean of episode rates. Click a row to explore that metric.

Per scenario

Each scenario’s value in each run (the mean if it ran more than once). Hover a cell to see how the episode ended. Arrows compare with the baseline run.

Metric explorer

Compare any two metrics, including single reward components or intervention types.
